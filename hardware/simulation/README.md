# Noise-aware simulation results

This directory holds the outputs of the Qiskit Aer noise-aware simulations that were performed **independently** of the physical hardware experiments (as stated in Section 5 of the manuscript).

Physical hardware job records, raw counts, and calibrations reside under:
- `hardware/ibm/`
- `hardware/ionq/`
- `hardware/raw_counts/`
- `hardware/calibrations/`
- `hardware/provider_raw/`

Do not mix simulation result files with the hardware execution records.
